# Contributing

Dziękujemy za rozwijanie ZuckerBot.

1. Utwórz issue opisujące problem lub zakres funkcji.
2. Pracuj na osobnej gałęzi.
3. Zachowaj granice modułów i model bezpieczeństwa.
4. Dodaj testy kontraktu, sukcesu oraz odmowy/niepowodzenia.
5. Uruchom wszystkie komendy z `docs/DEVELOPMENT.md`.
6. Uzupełnij dokumentację, `STATUS.md` i append-only `WORKLOG.md`, gdy zmiana wpływa na zakres projektu.
7. Otwórz PR z wyjaśnieniem ryzyka i sposobu rollbacku.

Nie przyjmujemy funkcji związanych z self-botami, spamem, kradzieżą tokenów, raidami, obchodzeniem ograniczeń usług lub nieautoryzowanym nagrywaniem.
