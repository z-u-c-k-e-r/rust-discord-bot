# ZuckerBot

ZuckerBot is an open, Lua-scriptable Discord automation platform with a secure Rust core and a web dashboard.

The project is being built as an extensible alternative to closed all-in-one bots: moderation, automations, music, community tools, engagement, utilities and custom server-specific workflows live in versioned Lua modules, while Discord connectivity, authorization, storage and privileged actions remain in Rust.

> Development status: initial platform bootstrap. See the feature matrix and roadmap in the first implementation pull request.
